# Retail Store Sales Analysis | Power BI


## Project Overview
This project focuses on analyzing retail store sales data using Microsoft Power BI. The dashboard helps understand sales performance, customer behaviour, product performance and regional sales trends through interactive visualizations.

## Objectives
- Analyze overall retail sales performance.
- Identify top-performing product categories.
- Understand regional sales distribution.
- Analyze monthly sales trends.
- Compare different payment methods.
- Calculate key business performance indicators.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## Dataset Description
The project uses three related CSV datasets:

1. **Orders** – Order details, dates, quantities, discounts, sales and payment methods.
2. **Customers** – Customer details, locations, regions and membership information.
3. **Products** – Product names, categories, brands, costs and prices.

*Note: This is a synthetic dataset created for learning and portfolio purposes.*

## Data Analysis Process
1. Data Import
2. Data Cleaning and Transformation
3. Data Modelling and Relationships
4. DAX Measures Creation
5. Data Visualization
6. Dashboard Development

## Dashboard Insights
- Total Sales
- Total Orders
- Total Customers
- Total Profit
- Sales by Product Category
- Sales by Region
- Monthly Sales Trend
- Sales by Payment Method
- Top 5 Products by Sales
- Order Status Analysis

## Project Outcome
Developed an interactive Power BI dashboard to explore retail sales performance and support data-driven business decisions.
